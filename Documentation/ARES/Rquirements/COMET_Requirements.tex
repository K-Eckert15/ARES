% =========================================================
% FUNCTIONAL REQUIREMENTS
% =========================================================

\begin{enumerate}

    \item The system shall detect launch, powered
    ascent, coast, apogee, and descent using
    onboard barometric and inertial sensors.

    \item The system shall use inertial measurements
    to prevent inappropriate barometric
    apogee detection during transonic flight.

    \item The system shall independently control
    its designated drogue and main
    deployment channels.

    \item The system shall initiate drogue
    deployment following valid apogee detection
    and main deployment at the configured
    descent altitude.

    \item The system shall provide independent
    electrical continuity monitoring for
    each deployment channel.

    \item The system shall verify battery voltage,
    sensor initialization, and deployment
    circuit continuity before flight.

    \item The system shall provide a designated
    external arming interface and prevent
    unintended deployment during normal
    preflight handling.

    \item The system shall record sensor
    measurements, flight states, battery
    voltage, and deployment events in
    onboard nonvolatile memory.

    \item The system shall retain recorded
    flight data following normal shutdown
    or loss of external power.

    \item The system shall provide a serial
    interface for configuration, diagnostics,
    and optional external telemetry.

    \item The system shall provide visual
    or audible indications of initialization,
    arming status, and detected faults.

    \item The system shall permit postflight
    retrieval and export of recorded data
    for performance evaluation.

    \item The system shall be capable of
    independent ground testing of its
    sensors, flight-event detection,
    and recovery outputs.

    \item The system shall operate independently
    of experimental payloads and
    communications systems.

\end{enumerate}
